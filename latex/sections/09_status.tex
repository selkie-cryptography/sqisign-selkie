\section{Current Status}
\label{sec:status}

\emph{Baseline interoperability} with the SQIsign v2.0.1 specification
and the reference C implementation is achieved.  The implementation
produces byte-identical key pairs on every \emph{known-answer test}
(KAT) vector at the NIST-I parameter set ($103$ key-generation
vectors), and signatures that verify on every signing KAT ($100$
vectors).  Signature \emph{byte}-equality with the reference holds on
all $100$ signing KATs, verified by a byte-interop cross-test harness
that drives a live C reference over both the baked vectors and fresh
seeds (\S\ref{sec:testing}).  The implementation
exercises the full pipeline
end-to-end: quaternion ideal arithmetic, the Deuring correspondence,
the $(2,2)$-isogeny chain on theta surfaces, and Montgomery-curve
verification.  This baseline is the foundation that
the rest of this paper documents reaching: the bugs surfaced from
specification ambiguity (\S\ref{sec:bugs}), the type-level invariants
that prevented entire bug classes (\S\ref{sec:types}), and the test
infrastructure that gates byte-equality with C ref (\S\ref{sec:testing}).

Section~\ref{sec:post-baseline} documents the post-baseline performance
and constant-time work in flight on top of this foundation.
