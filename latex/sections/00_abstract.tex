\begin{abstract}
SQIsign has the smallest signatures and public keys of any post-quantum
signature scheme.  It is also one of the hardest to implement correctly.
We describe \texttt{sqisign-selkie}, a Rust implementation of SQIsign~v2
for NIST-I, built from the specification and C reference implementation.
Along the way we found eight bugs in our theta-coordinate isogeny chain,
each traceable to an ambiguity in the specification or an implicit
convention in the reference code.  We catalog these bugs, explain how
they arose, and extract concrete lessons for anyone implementing
isogeny-based schemes from a spec.  We show how Rust's type system
enforces cryptographic invariants at compile time, and survey the
published constant-time techniques for SQIsign's quaternion arithmetic.
\end{abstract}
